# Enhanced Save System Modules

Project data modules for Enhanced Save System 2.0.

Copy this folder beside `addons/enhance_save_system`. Keep module registration in the project's `Config/save_modules.cfg`; the core addon never scans or overwrites this folder.

`session_progress_module.gd`, `narrative_global_module.gd`, and `narrative_slot_module.gd` are optional. Register them only when the project owns their runtime state.
